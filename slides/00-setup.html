Setup · once per laptop

Install Git and Node.js.

Mac · Terminal

xcode-select --install

A dialog opens: Install. That gives you Git. “Already installed”? Fine.

Node.js: the LTS installer from nodejs.org. With Homebrew: brew install node gh.

Windows · PowerShell · one line at a time

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned -Force
winget install --id Git.Git -e
winget install --id OpenJS.NodeJS.LTS -e

The first line lets npm run. winget asks to accept its agreements: Y. Windows asks to allow changes: Yes. “winget is not recognized”? Install App Installer from the Microsoft Store.

Then, in a new terminal · both

node -v
git --version

Close the terminal and open a new one after installing, or it won't find the new tools. You want Node v22.12 or newer.

{
  "$schema": "https://opencode.ai/config.json",
  "model": "openrouter/z-ai/glm-5.3-flash",
  "small_model": "openrouter/z-ai/glm-5.3-flash",
  "provider": { "openrouter": { "models": {
    "z-ai/glm-5.3-flash": { "options": { "reasoning": { "effort": "high" } } },
    "z-ai/glm-5.3": { "options": { "reasoning": { "effort": "high" } } }
  } } }
}

small_model: without it, OpenCode picks another model for small jobs, and the course key blocks that one.

"effort": "high" keeps thinking shorter than the default, max.

Windows: Notepad asks to create the file: Yes.

Setup · Claude Code · 1 of 2

Claude Code: install it.

Mac · Terminal

curl -fsSL https://claude.ai/install.sh | bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc

Windows · PowerShell · one line at a time

irm https://claude.ai/install.ps1 | iex
$p = [Environment]::GetEnvironmentVariable('Path', 'User')
[Environment]::SetEnvironmentVariable('Path', "$p;$HOME\.local\bin", 'User')

Why the extra lines: the installer puts claude in a folder your terminal doesn't search yet. They add that folder to your PATH, the list of folders where the terminal looks for commands. Once.

Then open a new terminal: claude --version shows a version number.
