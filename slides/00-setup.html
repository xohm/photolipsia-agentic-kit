Setup

Once per laptop, about 45 minutes. Best before day one. You need one agent: OpenCode with the course key (most of you), or Claude Code or Codex with your own plan.

Tested on Linux. The Mac and Windows commands follow each tool's own instructions, but nobody has run them on a real Mac or Windows laptop yet. If a step fails: troubleshooting, or ask in writing.

Setup · once per laptop

Install Git and Node.js.

Mac · Terminal

xcode-select --install

A dialog opens: Install. That gives you Git.

Node.js: the LTS installer from nodejs.org. With Homebrew: brew install node gh.

Windows · PowerShell · one line at a time

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned -Force
winget install --id Git.Git -e
winget install --id OpenJS.NodeJS.LTS -e

The first line lets npm run. The first time, winget asks to accept its agreements: Y. “winget is not recognized”? Install App Installer from the Microsoft Store.

Then, in a new terminal · both

node -v
git --version

Close the terminal and open a new one after installing, or it won't find the new tools. You want Node v22.12 or newer.

Setup · once per laptop

A GitHub account, and your name in Git.

1

github.com → Sign up. Free. Click the link in the email GitHub sends: you can't fork before that.

2

In a new terminal · Mac and Windows

git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global pull.rebase false

Use the email of your GitHub account. It is public in every commit you push. Want it private? Use GitHub’s noreply address: docs/student-setup.md.

The last line makes git pull merge your teacher's updates into your work.

3

Log in once, so git push works

Mac: install the GitHub tool once: the installer from cli.github.com (or brew install gh). Then, in a new terminal:

gh auth login

Answer: GitHub.com, HTTPS, Yes, Login with a web browser. Copy the one-time code, paste it in the browser, Authorize.

Windows: nothing to install. At your first git push, Git opens a GitHub login in your browser.

2 · Paste at the end, real key, save

3 · Reload

[Environment]::SetEnvironmentVariable('OPENROUTER_API_KEY', (Read-Host 'Paste the key'), 'User')

Setup · OpenCode · with the course key

OpenCode: install it, give it the course config.

Mac · Terminal

npm install -g opencode-ai@1
opencode --version
mkdir -p ~/.config/opencode
touch ~/.config/opencode/opencode.json
open -e ~/.config/opencode/opencode.json

Windows · PowerShell

npm install -g opencode-ai@1
opencode --version
New-Item -ItemType Directory -Force "$HOME\.config\opencode"
notepad "$HOME\.config\opencode\opencode.json"

You want version 1.x. Not brew install opencode: that is OpenCode 2. Mac says “EACCES”? docs/student-setup.md, section 1.

Paste this into the file (don't type it) and save

{
  "$schema": "https://opencode.ai/config.json",
  "model": "openrouter/z-ai/glm-5.3-flash",
  "small_model": "openrouter/z-ai/glm-5.3-flash",
  "provider": { "openrouter": { "models": {
    "z-ai/glm-5.3-flash": { "options": { "reasoning": { "effort": "high" } } },
    "z-ai/glm-5.3": { "options": { "reasoning": { "effort": "high" } } }
  } } }
}

small_model: without it, OpenCode picks another model for small jobs, and the course key blocks that one.

"effort": "high" keeps thinking shorter than the default, max.

Check: /models, on the first-run slide.

Setup · first run · every tool

First run: is it the right model?

1 · An empty test folder · Mac · Terminal

mkdir -p ~/hello-agent && cd ~/hello-agent

Windows · PowerShell

New-Item -ItemType Directory -Force "$HOME\hello-agent"
cd "$HOME\hello-agent"

2 · Start opencode, claude or codex, then type

Create hello.js that prints "Hello from GLM", then run it with node.

You see Hello from GLM (on a plan too: it's just the text)? You're set up. Some tools ask first: allow it. Quit with /exit.

3 · Which model is it using?

OpenCode: type /models. GLM-5.3-Flash (OpenRouter) must be selected. Not “GLM 5.3 FlashX”, not “GLM 5.3 Prime”: they look alike, and the course key blocks them.

GLM-5.3, not Flash: only for a hard problem, then switch back. Up to about 10× the cost, and it can't see images.

Asks for a key? /connect, choose OpenRouter, paste it.

Claude Code: /status shows your Claude account, or the auth token with the course key.

Codex: /status shows the account and model.

Later, start the agent in the folder you work in, never in your home folder: the rules and deny rules are in the project folder.
