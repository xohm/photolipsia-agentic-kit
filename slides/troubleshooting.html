The course key

ProblemFix
404 “… matching your guardrail restrictions …”, or 403 “not allowed”The tool asked for a model the course key doesn't allow. Check the model name in your config. OpenCode: is small_model set? In /models, pick GLM-5.3-Flash, not FlashX or Prime. Claude Code: are all model variables set?
403 “Budget limit exceeded”Your key's $3 for today are used up. It resets at midnight UTC (1 or 2 am in Zurich). Tell your teacher if it happens often.
401 “User not found” or “invalid key”Typo in the key, or the terminal doesn't see it. Windows: open a new terminal after setting the key. Mac: source ~/.zshrc. Run node tools/check-openrouter.mjs.
model_not_found, 404Typo in the model name. OpenCode needs openrouter/z-ai/glm-5.3-flash, Claude Code and Codex need z-ai/glm-5.3-flash.
The agent can't see the screenshot, or images are rejectedGLM-5.3 can't see images, GLM-5.3 Flash can. OpenCode: /models → GLM-5.3-Flash. Claude Code, Codex: /model.
Claude Code still uses your Anthropic loginIs the env block in ~/.claude/settings.json? Then /logout, quit, start again. /status must show https://openrouter.ai/api and Auth token: ANTHROPIC_AUTH_TOKEN.
Codex: “wire_api = chat is no longer supported”Use wire_api = "responses".
Codex ignores your providerIt must be in ~/.codex/config.toml (Windows $HOME\.codex\config.toml), not in a project's .codex/config.toml.

Your own plan

ProblemFix
Claude Code or Codex asks you to sign in again, or says you are not logged inClaude Code: quit, start claude and sign in in the browser. Codex: codex login. Then check with /status.
The agent stops because a usage limit is reachedYour plan's 5-hour window or weekly limit is used up (shared with the chat app). /usage shows it. Wait until it resets. To make it last: a smaller model with /model, and a new session for each new task.
Claude Code doesn't work with your free Claude planThe free plan does not include Claude Code. Use the course key with OpenCode: ask your teacher.
Codex doesn't work with ChatGPT Free or GoThe Codex CLI needs Plus or higher. Use the course key with OpenCode: ask your teacher.
Claude Code /status shows Auth token although you want your planThe course key's env block is still in ~/.claude/settings.json: the key beats a plan. Delete the block, then start claude again.

Any account

ProblemFix
Codex: npm run check fails with “EPERM”, “listen” or browser errorsCodex doesn't use the project's .codex/config.toml. Start Codex inside the project folder and answer yes to “Do you trust this folder?”. If it still fails, approve running the check outside the sandbox when Codex asks.
Windows: “running scripts is disabled on this system”Set-ExecutionPolicy -Scope CurrentUser RemoteSigned -Force, then a new terminal.
node or npm “not recognized” / “command not found”Open a new terminal after installing Node. Still not found: reinstall Node LTS.
opencode, claude or codex “not recognized” / “command not found”Open a new terminal after installing the tool.
Mac: npm install -g fails with “EACCES”See section 1, Mac only: npm says EACCES.
npm run check: “Chromium for Playwright is missing”npx playwright install chromium (about 300 MB, once).
npm run check says FAILED and npm adds many npm error linesNormal: npm reports that the check failed. Read the lines that start with check: and -.
npm run dev: “Port 5173 is in use”Another dev server is still running. Find its terminal and press Ctrl+C. Vite also tries 5174 by itself: read the URL it prints.
The agent hangs after starting npm run devThe server never ends, so the agent waits. Press Esc (or Ctrl+C) in the agent, and run npm run dev in your own terminal.
npm run check: “App not ready … within 10000 ms”The page never set window.__APP_READY__ = true. Look for a page error above it in the report.
A big scan is slow or jerkyConvert it to .rad and/or lower the detail with ?detail=0.5. See big-scans.md.
No Enter VR button in the splat viewerThe browser can't do VR. Mac browsers never can: use the Quest browser with npm run dev:vr. On Windows, Quest Link plus Chrome also works. See Example 2, prompt 7.
The Quest can't open the https://… address from npm run dev:vrSame Wi-Fi? University Wi-Fi often isolates devices: try a phone hotspot. Allow node through the firewall (Mac), or private networks (Windows).
Mac: git push asks for a username and passwordGit isn't logged in yet: gh auth login (section 1, Git and GitHub). A GitHub password never works here.
Windows: git add prints “LF will be replaced by CRLF”Harmless. Git stores the file correctly.
git pull: “Need to specify how to reconcile divergent branches”Run git config --global pull.rebase false, then git pull --no-edit upstream main again.
git pull: “Your local changes … would be overwritten”Commit your work first (git add -A, git commit -m "My work"), then pull again.
git pull prints CONFLICTgit merge --abort, then ask in the Discussions.
npm install fails with “Cannot read properties of null (reading 'edgesOut')”Old npm with a newer package. Update Node to the current LTS.
Windows: a firewall prompt when starting npm run devAllow on private networks, or cancel: the local page still works on your own laptop.

Blender, MCP and your own splats

ProblemFix
install-addon: “Could not find a Blender user addons directory”Open Blender once and close it. Then run install-addon again.
The agent can't connect to Blender, or has no Blender toolsBlender is open, the add-on is on, the side panel (N) says “Connected on port 9876”. Then restart your agent (/exit, then start it again). Claude Code and Codex: /mcp shows whether blender is there.
claude mcp add: “Invalid environment variable format: blender”Put --scope user between --env DISABLE_TELEMETRY=true and blender, as in section 1, Claude Code.
Blender doesn't show the scan as splatsYou need Blender 5.3 or newer. Use Material Preview or Rendered.
The splats are upside downIn the viewer: press F. In Blender: splats.load(path, flip=False), or the default flip.
macOS blocks SpirulaSystem Settings → Privacy & Security → scroll down → Open Anyway, then run it again.
Spirula's output folder is hidden, its name starts with ._Use --output-dir-name scene, as in step 2.
Training is very slowClose other programs that use the GPU.
git push doesn't upload my splatsOn purpose: public/splats/ is ignored by git. Keep your own copies.

Ask a question

Not in these tables? Ask in writing, in the course Discussions on GitHub. Your teacher answers there, and the next student finds the answer by searching.

  1. Search the Discussions first: maybe someone asked already.
  2. Not there? New discussion, category Q&A. The title: your problem in a few words.
  3. Write what you did (the command or the prompt), what you see (copy the message as text, not only a screenshot), Mac or Windows, and your tool and account.
  4. Discussions are public: never paste your key, or anything private.
  5. Solved? Click Mark as answer under the reply that helped.
